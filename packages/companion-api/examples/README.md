# Companion API Examples

These examples are local-dev payloads for the draft-first Companion API. They assume the local server is explicitly enabled, bound to `127.0.0.1`, and protected by a dev bearer token.

Write-like examples create reviewable draft groups only. They do not apply drafts or mutate ledger transactions until the user reviews and confirms inside Cavalry.

See the repository [Companion API overview](../../../docs/integrations/companion-api-overview.md) and [local development guide](../../../docs/integrations/companion-api-local-dev.md) for setup and safety constraints.
