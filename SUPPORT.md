# Support

Cavalry is an open-source project maintained on a best-effort basis. Community support cannot guarantee a response time, data recovery, or a particular release schedule.

## Questions and bug reports

Search the [documentation](docs/README.md) and [existing issues](https://github.com/juanm-builder/Cavalry/issues) first. If the problem is new, open an issue with:

- the Cavalry version, operating system, and CPU architecture;
- clear reproduction steps and the expected and actual behavior;
- the smallest synthetic example that demonstrates the problem; and
- the validation or troubleshooting steps already attempted.

Do not attach a real workbook, account details, transaction history, access token, API key, local configuration, crash dump, or unredacted log. Replace sensitive values with obvious placeholders and verify the attachment itself, not only the issue text.

Feature requests are welcome as issues when they explain the user problem and the smallest useful outcome. Please keep proposals compatible with Cavalry's local-first and explicit-review safety boundaries.

## Security and privacy

Do not use a public issue for a vulnerability, leaked credential, or sensitive-data exposure. Follow [SECURITY.md](SECURITY.md). For questions about current data handling that can be discussed without personal information, see [PRIVACY.md](PRIVACY.md) before opening an issue.

## Financial decisions

Cavalry organizes and summarizes user-provided financial information. Project maintainers cannot provide financial, tax, legal, or investment advice and cannot verify a user's records. Review important decisions with an appropriately qualified professional.

## Contributing a fix

Small, focused fixes are welcome. Read [CONTRIBUTING.md](CONTRIBUTING.md) before opening a pull request.
